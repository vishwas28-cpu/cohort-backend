Day 1 - Backend Learning 🚀
What I Learned Today

Today I started learning Backend Development.

1. Installing Packages Using NPM

I learned how to install packages from the NPM website into my project.

First, I initialized my Node.js project using:

npm init -y

This command creates a package.json file.

2. Installing a Package

I installed the cat-me package using:

npm i cat-me

This helped me understand how packages can be installed and used in a Node.js project.

3. Installing Express

I also learned how to install Express.js using:

npm i express

Express is used to build backend servers and APIs.

4. Creating a Server

I learned the basics of creating and starting a server using Express.js.

After installing packages, files such as these are created:

node_modules/
package.json
package-lock.json
